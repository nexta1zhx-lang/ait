# 日记（想到就写 → 一行搜索 + 币种筛选）

> 状态（2026-10-18）：已上线。入口在「开单分析」左侧一级 tab 的**第 4 格「日记」**
> （`LEFT_TABS` 里 `auto` 之后，见 [analyze.ts](../frontend/src/analyze.ts)）。

---

## 0. 用户定下来的

原话：「日记模块可以加入某些币种，总结」→「是我手动写日记。也不一定是日记，
有可能是一周才写一次。最后，都是按月给我汇总到一起」
→ **当天改口**：「**不要自动按月总结了，默认排版，不显示什么总结，就是每日感想，可以筛选**」。

| 决定 | 落地方式 |
|---|---|
| **手动写**，不接模型 | 正文全是纯 textarea，一个字都不生成 |
| **不一定每天** | 条目按日期存，一个月 0~N 篇都行；不提醒、不打卡 |
| **不要汇总 / 不要总结** | ~~月度统计~~ / ~~缺口提示~~ / ~~月度总结框~~ 全删了（当天就撤） |
| **默认排版** | 进来就是**倒序的感想流水**，不按月分页、不用先选月份 |
| **可以筛选** | 顶上就一行：**搜标题或正文** + **币种下拉（默认「全部」）** |

⛔ 所以这一页**没有任何模型调用**，也不打交易所 —— 纯读库写库，随便刷。

## 1. 两张表

| 表 | 存什么 | 关键点 |
|---|---|---|
| `journal_entries` | 一篇：`day` / `title` / `body` | `day` 是**北京时间的日子**（`YYYY-MM-DD`），同一天允许多篇 |
| `journal_coins` | 一篇挂了哪些币，每个币一句备注 | `(entry_id, base)` 唯一；一篇最多 20 个 |

表定义在 [schema.ts](../backend/src/db/schema.ts)，读写全在 [journals.ts](../backend/src/db/journals.ts)。

> ⚠️ 曾经还有一张 `journal_months`（月度总结）。用户当天改口后**已从 schema 删掉**，
> 线上库里那张表还留着但没人读 —— 别再用它。
> ⚠️ `schema.ts` 里那段是 **JS 模板字符串**（`SCHEMA_SQL`），SQL 注释里**不能出现反引号**，
> 否则从这里截断、后面整段 SQL 都失效（踩过两次）。

## 2. 列表与筛选

`listJournalEntries(userId, {coin, q, limit, offset})`：

- **倒序**：`day DESC, id DESC`（同一天后写的在上）。
- `coin`：这个币出现在 `journal_coins` 里才算命中。
- `q`：`title` 或 `body` 里**包含**这个词（`ILIKE`，`%` / `_` 已转义）。
- 两个一起给 = 同时满足。
- 一页 30 条；`count(*) OVER ()` 顺带把总数带回来，页面据此显示「还有 N 篇」。
- 返回值里还有 `coins`：**写进过日记的全部币**（去重、按字母排）—— 就是筛选下拉的选项。

> ⚠️ 空关键词不能用 `ILIKE '%'` 短路：`title` 是可空列，`NULL ILIKE '%'` 还是 NULL，
> 没写标题的条目会被漏掉。所以 SQL 里写 `($3::text = '' OR ...)`。

## 3. 条目

- 一行：`10/17 周六 · 标题（没标题就用正文第一行）· 挂的币 · ▾`。
- 点一行展开：正文（`white-space: pre-wrap`）+ 每个币后面自己写的那句话 + 「编辑 / 删除」。
- 删除走**站内确认框**（`askConfirm`），不用 `window.confirm`。
- 点币名 → 跳 K 线并**把图定在提到它的那一天**（`chartFrom = 那天T12:00`，`KlineChart`
  的 `centered` 那套还认它）；窄屏同时切到「K 线」那格。

---

## 4. 接口

| 方法 | 路径 | 干什么 |
|---|---|---|
| GET | `/api/journal/entries?coin=&q=&limit=&offset=` | 倒序列出（筛选 + 分页） |
| POST | `/api/journal/entries` | 新建 / 更新一条（带 `id` 就是更新），带 `coins: [{base, note}]` |
| DELETE | `/api/journal/entries/:id` | 删一条 |

上限（后端卡死，前端不提示）：一篇最多 20 个币、标题 120 字、正文 20000 字、单个备注 200 字。
