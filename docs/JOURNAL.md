# 交易日记（手动写 → 按月汇总）

> 状态（2026-10-18）：已上线。入口在「开单分析」左侧一级 tab 的**第 4 格「日记」**
> （`LEFT_TABS` 里 `auto` 之后，见 [analyze.ts](../frontend/src/analyze.ts)）。

---

## 0. 用户定下来的三件事

原话：「日记模块可以加入某些币种，总结」→「是我手动写日记。也不一定是日记，
有可能是一周才写一次。最后，都是按月给我汇总到一起」。

| 决定 | 落地方式 |
|---|---|
| **手动写**，不接模型 | 正文、月度总结全是纯 textarea，一个字都不生成 |
| **不一定每天** | 条目按日期存，一个月 0~N 篇都行；不提醒、不打卡、不计算「连续天数」 |
| **按月汇总** | 上面一条月份切换（◀ 2026-10 ▶），中间是自动算出来的月度统计 |

⛔ 所以这一页**没有任何模型调用**，也不打交易所 —— 纯读库写库，随便刷。

---

## 1. 三张表

| 表 | 存什么 | 关键点 |
|---|---|---|
| `journal_entries` | 一篇日记：`day` / `title` / `body` | `day` 是**北京时间的日子**（`YYYY-MM-DD`），主键自增 |
| `journal_coins` | 一篇日记挂了哪些币，每个币一句备注 | 同一篇里 `(entry_id, base)` 唯一；上限 20 个 |
| `journal_months` | 月度总结（自己写的那一段） | 主键 `(user_id, month)`，`month` 形如 `2026-10` |

三张表都挂 `user_id`，跨用户互不可见。表定义在
[schema.ts](../backend/src/db/schema.ts)，读写全在 [journals.ts](../backend/src/db/journals.ts)。

> ⚠️ `schema.ts` 里那段是 **JS 模板字符串**（`SCHEMA_SQL`），SQL 注释里**不能出现反引号**，
> 否则从这里截断、后面整段 SQL 都失效（踩过两次）。

## 2. 月份口径

- **月界按北京时间（`+08:00`）算**：`monthWindow('2026-10')` → `['2026-10-01T00:00+08',
  '2026-11-01T00:00+08')`。跟库里的成交时间（`timestamptz`）直接比。
- 「今天 / 这个月」由 `bjDayNow()` / `bjMonthNow()` 给（`server.ts`），**不用**服务器本地时区。
- 编辑器里选日期时，如果不是当月，默认填**那个月的 1 号**（不然「补上个月」会默认成今天，
  存进去就跑到别的月份去了）。

---

## 3. 月度统计（全是自动算的，不用手填）

`getJournalMonth()` 返回四块：

### 3.1 汇总条

`X 篇 · 提到 N 个币 · 成交 M 笔 · 净 ±P USDT`

- 「成交 / 净」只统计**日记里提到的那些币**，不是整月账户。
- 净盈亏 = `sum(realized_pnl - fee)`（`exchange_fills`），跟上位那些分析页同一口径。

### 3.2 币的 chips

每个币一颗：`BTC · 2` + 月涨跌 + 「只看」标。

- **月涨跌** = 该币**第一根日线开盘** → **最后一根日线收盘**（`kline_1d`），不是最新价 ——
  月中看日记时，用最新价会把「当天的波动」当成整月表现。
- **「只看」标** = 这个月在这个币上**一笔成交都没有**（`fills = 0`）。写了但没做，是复盘里
  最值得认的一类：想法有没有落地。

### 3.3 缺口提示：交易过、但一篇没写

`missing` —— 这个月 `exchange_fills` 里有成交、但 `journal_coins` 里没出现的币。

- **按成交笔数多的在前**，页面只露前 5 个，其余折成「还有 N 个」。
  ⚠️ 一个月的成交可能摊在四五十个币上（实测 46 个），全铺出来会把面板撑爆，
  而真正该补的是**做得最多的那几个**。
- 每个 chip 的 title 里写着「这个月成交 X 笔」，点一下跳 K 线。

### 3.4 「这个月还没写」

一篇都没有时只给一句提示：不用天天写，想到就记。

## 4. 条目

- 列表按 `day` **倒序**（新的在上），标题缺省时用正文头一行。
- 点一行展开看全文；展开后有「编辑 / 删除」。删除走**站内确认框**（`askConfirm`），
  不用 `window.confirm`。
- 每条挂的币，点币名 → 跳 K 线并把图**定在提到它的那一天**（写 `chartFrom = 那天T12:00`，
  `KlineChart` 的 `centered` 那套还认它）。左侧/手机上会同时切到「K 线」格。

---

## 5. 接口

| 方法 | 路径 | 干什么 |
|---|---|---|
| GET | `/api/journal?month=2026-10` | 一个月的全部：条目 + 统计 + 月度总结 |
| GET | `/api/journal/months` | 有日记的那些月份（月份切换用） |
| GET | `/api/journal/coin?base=BTC` | **单个币**跨月反查（后端已实现，前端还没接） |
| POST | `/api/journal/entries` | 新建一篇（带 `coins: [{base, note}]`） |
| DELETE | `/api/journal/entries/:id` | 删一篇 |
| PUT | `/api/journal/summary` | 存月度总结（失焦自动存） |

上限（后端卡死，前端不提示）：一篇最多 20 个币、标题 120 字、正文 20000 字、单个备注 200 字。
