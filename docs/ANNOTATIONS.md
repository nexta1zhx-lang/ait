## 它是什么

- **按用户、按币种**记一条「我当时怎么看这个币」：一组标签 + 保存时刻
  （老数据里可能还有一句描述，新标注不再写）。
- 不是预测历史，也不是交易日记：预测历史是模型结论，日记是整篇感想，标注是**贴在币上的短记**。
- 时间只由服务端 `now()` 决定（按保存那一刻），不绑定某根 K 线 / 某个价格。

## 数据表

两张表，建表见 `backend/src/db/schema.ts`：

### `annotation_tags`

标签词表（杂毛 / 异能 …），只用来给弹窗挑。

| 列 | 说明 |
| --- | --- |
| `id` | 主键 |
| `user_id` | 用户（`ON DELETE CASCADE`） |
| `name` | 标签名（最长 12 字，同一用户不区分大小写唯一） |
| `color` | 标签色（`#rrggbb`；老标签为空时列表接口按调色板补一个） |
| `sort` | 维护顺序 |
| `created_at` | 创建时刻 |

### `symbol_annotations`

一条标注 = 一个币 + 当时选中的标签名 + 描述 + 时刻。

| 列 | 说明 |
| --- | --- |
| `id` | 主键 |
| `user_id` | 用户（`ON DELETE CASCADE`） |
| `base` | 基础币（`BTC`，不带 `/USDT`） |
| `tags` | 标签名数组（JSONB，如 `["杂毛","异能"]`） |
| `note` | 描述（可空，最长 500 字） |
| `created_at` | 标注时刻 |

索引：`(user_id, base, created_at DESC, id DESC)` 走某币历史；
`(user_id, created_at DESC, id DESC)` 走「每个币最新一条」。

`users.annotation_tags_seeded_at` 只用来判断默认标签有没有播种过：第一次列标签时种下
`杂毛` / `异能` 并写 `now()`；用户删光后不会自己长回来。

## 标签语义

- 标注里存的是**名字快照**，不是标签 id。
- **颜色 = 色系**（2026-10-20）：`annotation_tags.color` 只认三个色系值
  （`TAG_FAMILY_COLORS` 的红 / 绿 / 黄）。不在三色里的值（老调色板、空串）前端画成**灰**，
  用户在「管理标签」里点圆点归色后写回这三色之一。
- **改名**：后端会把历史标注里的同名标签一起改（`jsonb_array_elements ... WITH ORDINALITY`，
  保持顺序）。理由：用户维护的是同一份标签口径，改名后旧记录还挂旧名字会让行情列表和
  K 线历史同时出现两个看起来是一回事的标签。
- **删除标签**：不动历史里的名字。历史是「当时贴了什么」，词表只是以后可选的集合。
- 新建标签时后端仍会补一个占位色（老调色板），前端看到不是三色就画灰。
- 每条标注最多 8 个标签；每用户最多 50 个标签。后端仍然允许只写描述不选标签
  （`note` 可空），只是新前端不再提供描述输入框。

## 接口

全部要登录，全部按 `user_id` 隔离（`backend/src/server.ts`，实现见 `db/annotations.ts`）。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/annotations` | `{tags, latest: {BTC: {id, base, tags, note, at}}}`，每个币最新一条 |
| GET | `/api/annotations?base=BTC` | `{tags, entries: [...]}`，某币全部历史（新的在前，最多 200 条） |
| POST | `/api/annotations` | body `{base, tags?, note?}` → `{entry}` |
| DELETE | `/api/annotations/:id` | `{ok}`，只能删自己的 |
| POST | `/api/annotation-tags` | body `{name, color?}` → `{tag, tags}`；不传 color 用默认色（前端现在只传 name） |
| POST | `/api/annotation-tags/:id` | body `{name?, color?}` → `{tag, tags}`（改名 / 改色；改名时历史同步；前端现在只传 name） |
| DELETE | `/api/annotation-tags/:id` | `{tags}`（历史不动） |

`tags[]` / `tag` 里都带 `color`（`#rrggbb`）。`at` 是 ISO 时间；前端用 `format.ts` 的
`ago()` 转成「几分钟前」。

## 前端

| 文件 | 作用 |
| --- | --- |
| `frontend/src/annotations.ts` | 模块级 store：标签词表 / 最新一条 / 某个币的历史；20 秒新鲜度 + 请求序号防串；三色系 `tagFamilyOf` / `tagChipStyle` |
| `frontend/src/comps/AnnotationSheet.vue` | 底部弹窗：按色系分组选标签、快速加标签、管理（改名 / 色系 / 删除） |
| `frontend/src/comps/MarketPanel.vue` | 合约行情币种后面那一行的标签（统一配色，无时间） |
| `frontend/src/views/AnalyzeView.vue` | 顶部按钮（测试左边第一颗）、开仓按钮下方标注区、弹窗入口 |

界面口径：

- 行情列表只显示**最新一条**的标签（**最多 2 个**，其余折成 `+N`），放在**币种后面**，
  按色系上色；**不显示时间**（时间只在 K 线底部的历史里看）。
  币种列窄，2 个标签可能落到第二行，行高会高一点（52 → 69px），价格 / 涨跌仍然上下居中。
- K 线顶部：币种后面跟最多 2 个标签（三色系）；右侧那颗价签按钮有标注时染主题金色，点开是弹窗。
- 弹窗里标签按色系分组，选中的加字重 + 一圈本色细环；没有描述输入框了。
- 弹窗标题右边那颗**时钟**开关历史面板（历史只在弹窗里看，页面上不再有那块）。
- 页面上**没有**标注区了：历史在标注弹窗里（时钟图标），最新的标签在 K 线头部币种后面。
- 历史面板：一条一个卡片，标签 + 时间（`10/20 23:16 · 37 分钟前`）+ 删除图标；
  列表最高 300px 内部滚动；每条可删（确认框）。

## 自测

```bash
npm run typecheck
npm run ui:build
npm run selftest
```

本地起服务后（`npm run web`），可用 `/api/auth/dev-login` 拿 token 走一遍：

1. 首次 GET `/api/annotations` 出现 `杂毛` / `异能`；
2. POST 一条标注 → GET 汇总能看到最新一条；
3. GET `?base=` 历史新的在前；
4. 改名标签 → 历史里的同名标签同步变；
5. 改标签名 → 行情行 / 弹窗 / 历史里的同一个标签一起改名；
6. 点「管理标签」里某个标签的色系圆点 → 行情行 / 弹窗 / 历史里同一个标签一起换色；
7. 删除标签 → 历史名字保留、词表里消失；
8. POST 一条只带 tags 的标注（不传 note）→ 能存下来；
9. DELETE 标注 → 汇总 / 历史都消失；
10. 未登录 GET 返回 401。
